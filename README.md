# Dashboard Meteorológico

## Objetivo del Proyecto
Este proyecto consiste en el desarrollo de una interfaz de usuario interactiva (dashboard) para el monitoreo y análisis de datos meteorológicos en tiempo real. Utiliza la API de Open-Meteo para extraer variables climáticas actuales, por hora y diarias, facilitando la visualización de estadísticas y la toma de decisiones basada en datos confiables.
